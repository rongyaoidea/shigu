## 已完成并验证

- Android APK 可编译、可安装、可跑真机数据。
- 数据源：
  - 新浪股票 / 北交所 / ETF 列表；
  - 腾讯前复权日线（`proxy.finance.qq.com`）；
  - BSE 走新浪不复权兜底；
  - 沪深300 基准。
- 本地 SQLite：股票、日线、估值、观察、策略、纸面组合、净值。
- 当前模拟器实测：**6,468 个资产**（BSE 355、ETF 890、沪深/创业板/科创板 5,223），92,674 条日线（快速池 300）。
- 因子库 **47 个**，含 RSRS 右偏/标准分/斜率/R²、LLT、球队硬币、量价背离、换手/成交额稳定、隔夜距离、特质波动、MAX、偏度、峰度、Amihud 等；新增上市天数、ROE、毛利率、净利率、营收/净利增速、资产负债率、EPS/BPS、每股经营现金流。
- 基础过滤：企业性质（央企/地方国企/民企/外资/无实控人/未知）、ST/*ST/退市整理、停牌、上市天数、板块、价格/成交额、PE/PB 上限、市值区间。
- 东方财富 F10 基础资料批量同步已验证：**5,578 只**（覆盖 6,468 个资产中的全部 A 股；ETF 无 F10 资料），报告期 2026-09-30；企业性质分布：民企 4,036、地方国企 976、央企 475、无实控人 82、外资 7、未知 892（主要是 ETF）。
- 6 个内置策略 + 用户从因子页保存的自定义策略。
- 回测：100 万初始资金、整手、次日开盘、等权、成本、止损/止盈/最大持有、涨停不买/跌停不卖、基准/超额/回撤/夏普。
- 策略卡显示：
  - 概览回测（1 年/300 池）；
  - 创建后收益；
  - 有调仓时红色 `调仓 · 买N 卖N` 标志。
- 模拟页：
  - 所有策略的创建后收益、目标持仓/实际持仓；
  - “今日调仓”汇总；
  - 底部“策略/模拟”红点。
- 每日 16:10 WorkManager 同步 → 策略重算 → 纸面持仓对比 → 本地通知。
- 策略可编辑：
  - 在策略页直接改因子权重、持仓数、调仓/止损；
  - 自定义策略“保存修改”会重置创建后模拟（从今天重新开始）；
  - 内置策略“另存为我的策略”创建新策略。
- 模拟详情：
  - 点策略卡“详情 →”查看创建后收益、基准、现金、实际持仓；
  - 有净值点时显示纸面净值曲线；无点时提示等待收盘；
  - 顶部“立即核对 →”可手动触发一次纸面组合重算。
- 因子页与策略页分离；因子页有“存为策略”；策略页有“去因子页组策略”。
- 单元测试：`BacktestEngineTest` 验证回测产生交易/持仓、现金不为负；`OwnershipClassifierTest` 覆盖央企/地方国企/民企/外资/无实控人、姓名误判与 ST 状态解析。

## 尚未验证 / 已知缺口

- 企业性质是按实控人/第一大股东名称做的启发式推断，不是官方标签；已修复“韩国龙→韩国”“张江波→张江”这类姓名误判，但仍可能有边界样本。
- 财务因子是最新报告期快照；历史回测使用当前值，存在前视偏差，回测结果会带警告。
- ST / 停牌 / 上市天数 / 企业性质都是当前快照，历史回测同样有前视偏差。
- 16:10 的每日自动同步与通知未在真实收盘后等待验证；代码路径已接好。
- 估值历史（东方财富）可能限流；价值因子历史回测不保证完整。
- ETF 池按名称剔除货币/短融/债券型，是启发式。
- BSE 日线不复权。
- 回测无冲击成本、涨跌停排队、分红税、融券费用。
- 纸面组合重算依赖当日日线；如果数据源缺当天，策略不会错误调仓。
- 当前池有幸存者偏差；已退市资产不在内。
- 纸面净值曲线在策略创建当天只有 1 个点，最早次日收盘后才有可看的曲线。
- 编辑自定义策略会重置模拟；目前不保留旧版本历史。

## 下一步建议

1. 用真实交易日观察一次 16:10 自动同步 + 通知 + 红标。
2. 给 `PaperRepository` 增加单元测试（用临时 SQLite/面板）覆盖买/卖/持有/清仓。
3. 把估值历史同步做成分批/可恢复，支持价值因子完整回测。
4. 策略编辑：直接修改已保存策略的因子/规则，而不是另存。
5. 因子 IC / 相关性 / 分层收益面板（Qlib Factor Lab 方向）。
6. 纸面净值曲线页面（目前是卡片 + 目标持仓，未画逐日净值）。
