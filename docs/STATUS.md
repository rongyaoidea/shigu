## 已完成并验证

- Android APK 可编译、可安装、可跑真机数据。
- 数据源：
  - 新浪股票 / 北交所 / ETF 列表（稳定 `sort=symbol` 分页，避免重复/漏股票）；
  - 腾讯前复权日线（`web.ifzq.gtimg.cn`；旧 `proxy.finance.qq.com` 会返回 501）；
  - 基准腾讯失败时走新浪兜底；
  - BSE 走新浪不复权兜底；
  - 沪深300 基准。
- 本地 SQLite：股票、日线、估值、观察、策略、纸面组合、净值、交易流水、状态变化历史、财报历史。
- 当前模拟器实测：**6,469 个资产**（BSE 356、ETF 890、沪深/创业板/科创板 5,223），96,575 条日线（快速池 300）。
- 因子库 **51 个**，含 RSRS 右偏/标准分/斜率/R²、LLT、布林位置、MFI14、RSI21、球队硬币、量价背离、换手/成交额稳定、隔夜距离、特质波动、MAX、偏度、峰度、Amihud 等；新增上市天数、ROE、毛利率、净利率、营收/净利增速、资产负债率、EPS/BPS、每股经营现金流。
- 因子研究：
  - z-score / 排名两种打分；
  - 单因子体检：Rank IC、ICIR、正 IC 比例、Top-Bottom 十分位、覆盖率；
  - 自定义因子公式：`+ - * / ^`、括号、abs/sqrt/log/min/max/clip；变量用 FactorKey.name 或 RSRS/ROE/PE/MKT_CAP 等别名；保存后按权重加入筛选/策略；
  - 因子相关性：当前截面 Pearson 相关，列出高度重叠的因子对，|r|>0.7 标红；
  - 个股卡显示因子分数贡献；
  - 因子库搜索、分类、等权、权重归一化。
   - 可不选内置因子，点“应用 0 个因子”，只按基础过滤和自定义因子筛选；个股卡显示“仅基础筛选”。
- 基础过滤：企业性质（央企/地方国企/民企/外资/无实控人/未知）、ST/*ST/退市整理、停牌、上市天数、板块、价格/成交额、PE/PB 上限、市值区间、只看资料完整。
- 筛选漏斗：全池 → 板块/资产 → 价格/流动性 → ST/停牌 → 企业性质 → 上市天数 → 估值/市值 → 资料完整 → 因子覆盖 → TopK；每一步显示剩余与淘汰原因。
- 组合层：按每个策略 100 万名义本金合并，显示组合纸面/收益/现金、Top 10 合并持仓、重叠持仓、最大单票、策略日收益相关性。
- 策略对比：勾选 2–4 个策略，对比回测/创建后收益、回撤、夏普、交易数、费用、共同持仓数。
- 调仓预览：按当前目标 TopK、等权、整手、收盘价估算买卖清单、金额、费用、换手；实际以调仓日开盘为准。
- 数据质量：个股页标记北交所不复权/停牌/资料未同步；数据页显示北交所、ST、停牌数量；基础过滤可勾“只看资料完整”。
- 纸面冻结账本：schema v7 新增 `paper_ledger`，逐日净值/持仓/现金/调仓提示 `INSERT OR IGNORE`，同一交易日不重写；旧 `paper_equity` 与新账本合并展示。
- v0.10.0 起只做股票/ETF，移除期权模块；升级时删除 option_contracts/option_strategies/option_backtest_runs/option_chain_history。
- 东方财富 F10 基础资料批量同步已验证：**5,579 只**，报告期 2026-09-30；财报历史 **6,705 条**（含公告日），状态变化历史 6,469 条。
- 6 个内置策略 + 用户从因子页保存的自定义策略。
- 回测：100 万初始资金、整手（科创 200）、次日开盘、等权、佣金 8bps + 卖出印花税 5bps + 过户费 + 滑点 5bps、止损/止盈/最大持有、涨停不买/跌停不卖、基准/超额/回撤/夏普、累计费用。
- 调仓只卖出跌出目标的持仓，仍在目标里的继续持有，不再“全部卖出再买回”。
- 策略卡显示：
  - 概览回测（1 年/300 池）；
  - 创建后收益；
  - 有调仓时红色 `调仓 · 买N 卖N` 标志。
- 模拟页：
  - 所有策略的创建后收益、目标持仓/实际持仓；
  - 组合纸面合计、平均收益；
  - 策略卡同时显示“回测收益（过去 1 年 / 300 池）”和“创建后纸面收益”，创建日为中间分割线；
  - “今日调仓”汇总；
  - 底部“策略/模拟”红点。
- 每日 16:10 WorkManager 同步 → 策略重算 → 纸面持仓对比 → 本地通知。
- 策略可编辑：
  - 在策略页直接改因子权重、持仓数、调仓/止损；
  - 自定义策略“保存修改”会重置创建后模拟（从今天重新开始）；
  - 内置策略“另存为我的策略”创建新策略。

## 尚未验证 / 已知缺口

- 企业性质是按实控人/第一大股东名称做的启发式推断，不是官方标签；已修复“韩国龙→韩国”“张江波→张江”这类姓名误判，但仍可能有边界样本。
- 财务因子是最新报告期快照；历史回测使用当前值，存在前视偏差，回测结果会带警告；财报历史已开始落库，但尚未接入 as-of 回测。
- ST / 停牌 / 上市天数 / 企业性质已开始记录状态变化历史；历史长度不足时仍回退当前值。
- 纸面账本已冻结历史净值/逐日持仓，但当天仍从创建日重算；尚未持久化待执行订单、成交明细和分红/拆股，不是严格的增量执行账本。
- 16:10 的每日自动同步与通知未在真实收盘后等待验证；代码路径已接好。
- 估值历史（东方财富）可能限流；价值因子历史回测不保证完整。
- ETF 池按名称剔除货币/短融/债券型，是启发式。
- BSE 日线不复权；成交额/换手为估算。
- 回测无冲击成本、涨跌停排队、分红税、融券费用；无行业中性、无 walk-forward、无导出/导入。
- 纸面组合重算依赖当日日线；如果数据源缺当天，策略不会错误调仓。
- 当前池有幸存者偏差；已退市资产不在内。
- 编辑自定义策略会重置模拟；目前不保留旧版本历史。

## 下一步建议

1. 纸面模拟改成严格增量订单账本：持久化待执行订单/成交明细，按交易日增量执行；当前已完成历史日期冻结。
2. 行业中性/市值中性 + 因子相关性矩阵/推荐子集，避免 51 个因子互相重复。
3. 自定义因子公式（ROE/PE、营收-净利增速等），保存后参与打分和体检。
4. 策略版本历史/克隆/A-B 测试；当前已有策略对比，但没有版本回滚。
5. 多基准（沪深300/中证500/中证1000/自定义）与条件提醒/通知中心。
6. Walk-forward / 参数敏感性 / 成本敏感性报告。
7. 导出/导入策略、观察池、纸面账本；当前备份只含策略/观察。
8. 接入真实成交额/换手，北交所复权数据；ETF 份额与资产类别标签。
9. 用真实交易日观察一次 16:10 自动同步 + 通知 + 红标。
10. Panel/FloatArray/跨策略缓存，降低 1200–1500 池回测的内存和耗时。
