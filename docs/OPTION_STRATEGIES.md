# ETF 期权方向策略：5 年回测与研究记录

> 研究目的：给 510050 / 510300 的期权方向选择找“过去 5 年能跑赢大盘”的策略，并把通过筛选的策略内置到 App。
>
> **重要限制**：免费数据源没有 5 年历史期权链和盘口。回测中的期权价格用 Black-Scholes + 20 日历史波动率模拟，不是实际成交价；结果用于比较方向策略，不等于真实期权收益。详见第 6 节。

## 1. 回测设定

| 项目 | 设定 |
|---|---|
| 标的 | 510050 上证 50ETF、510300 沪深 300ETF |
| 区间 | 2021-11-17 ~ 2026-11-17（5 年） |
| 数据 | 东方财富前复权日线，约 1600 条；沪深 300 为基准 |
| 信号 | 收盘生成，次日开盘执行；不使用未来数据 |
| 合约 | 最近到期月（第四个周三），剩余 >=10 天；剩余 <=3 天滚动 |
| 行权价 | ATM（可按 ±1/±2 档偏移）；510050 网格 0.05，510300 网格 0.10 |
| 定价 | Black-Scholes，r=2%，q=0，IV = 20 日历史波动率 × 1.05；另做 1.20 压力测试 |
| 仓位 | Delta 匹配 1 倍名义本金；权利金不超过现金；1 张 = 10,000 份 |
| 费用 | 5 元/张 + 单边 0.5% 权利金滑点；到期按内在价值结算 |
| 基准 | ETF 买入持有、沪深 300 买入持有 |

## 2. 候选策略

共测试 38 组参数/策略，覆盖：

- **趋势**：MA20/60、EMA10/30、三均线、MA200、Donchian 20/55/100、布林突破、MACD、Aroon、ADX/DI、KAMA、ATR/Keltner 通道；
- **反转**：MFI 10/14/20、RSI 7/14/21、BIAS、布林回归；
- **动量**：20/60/120 日动量、双动量、相对沪深 300 强弱；
- **事件**：单日/5 日恐慌、跳空反转、月末效应；
- **过滤**：量能、波动率状态、MA200 趋势过滤。

结论很集中：

- 2021-2026 是震荡/下跌市，趋势策略在期权上被 theta 和反复翻向消耗，5 年大多为负；
- 真正同时跑赢 ETF 和沪深 300 的，是**均值回归/恐慌反弹**这一类；
- 参数高原上最稳的是 **MFI14 20/80**；RSI21 25/75、MFI 25/75 在基准 IV 下收益更高，但对 IV 更敏感。

## 4. IV = 1.20 压力测试

把 IV 提高 20% 后，510300：

| 策略 | 期权收益 |
|---|---:|
| MFI 超跌反转 20/80 | **+48.56%** |
| 单日恐慌反弹 | +6.74% |
| 五日恐慌反弹 | +3.97% |
| RSI21 超跌反转 | 转负 |
| MFI 宽幅反转 | 转负 |

510050 在压力测试下 MFI 仍为正，RSI21/MFI 宽幅也仍为正；但两个 ETF 同时稳的只有 **MFI 20/80** 和两种恐慌反弹。因此：

- 默认策略：**MFI 超跌反转 20/80**；
- 进取策略：MFI 宽幅、RSI21、布林 30 日回归；
- 事件策略：单日/五日恐慌反弹（交易少、回撤小，但样本只有 5–9 笔）。

## 5. App 内置策略

原有 5 个趋势策略保留作对照：

- RSRS + LLT
- LLT + 均线
- 双均线方向
- 量价动量
- 综合方向

新增 6 个回测候选：

| id | 名称 | 规则 |
|---|---|---|
| mfi_reversion | MFI 超跌反转 | MFI14<20 买 call，>80 买 put，持有到反向极值 |
| mfi_reversion_wide | MFI 宽幅反转 | 25/75 阈值，信号更多 |
| rsi21_reversion | RSI21 超跌反转 | RSI21<25 买 call，>75 买 put |
| panic_1d | 单日恐慌反弹 | 单日跌 3% 买 call，反弹 1% 或 RSI>55 卖出 |
| panic_5d | 五日恐慌反弹 | 5 日跌 6% 买 call，5 日反弹 2% 或 RSI>55 卖出 |
| boll_reversion_30 | 布林 30 日回归 | 跌破下轨买 call，突破上轨买 put |

期权页的「5 年历史回测」可对当前标的运行全部内置策略，显示期权收益、最大回撤、夏普、交易数、胜率和净值曲线；IV 可切换 1.05/1.20。

## 6. 不能忽略的限制

- 没有历史期权盘口，期权价格是理论价；实际 IV 曲面、期限结构、买卖价差、冲击成本都会不同；
- 未模拟保证金、实物交割、行权交收和停牌；
- 到期日按第四个周三，未处理节假日顺延；
- 恐慌策略交易笔数少（5–9 笔），统计显著性有限；
- 过去 5 年跑赢不代表未来；这不是投资建议，也不接券商。
