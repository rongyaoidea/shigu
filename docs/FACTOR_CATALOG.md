## 使用建议

- 先用“体检”看 Rank IC / ICIR / 覆盖率，再决定是否纳入组合。
- 相关性高的因子不要重复加权；例如 RSRS 三兄弟、VOL20/VOL60/ATR。
- 快照因子（估值/财务/企业性质）在历史回测里是常数或当前值，存在前视偏差；界面会警告。
- 因子只描述历史截面，不是预期收益。

## 自定义因子

在因子页点“自定义 → 新建公式”，用现有因子做算术：

```text
ROE / PE
REVENUE_GROWTH - PROFIT_GROWTH
RSRS_RIGHT / VOL20
clip(ROE / PE, 0, 5)
```

- 变量名：`FactorKey.name`（如 `RSRS_RIGHT`、`VOL20`、`ROE`），也支持别名 `RSRS`、`LLT`、`MKT_CAP`、`AMT`、`TURN` 等。
- 运算符：`+ - * / ^`、括号；函数：`abs`、`sqrt`、`log`、`exp`、`min`、`max`、`clip`、`sign`。
- 方向、单位、说明可自定义；保存后默认按 20% 权重加入当前筛选，可再调权重。
- 策略 JSON 内嵌自定义因子定义，保证策略自包含；编辑公式库不会改写旧策略里的公式版本。
- 自定义因子参与 z-score/排名打分、回测和纸面模拟；目前单因子“体检”和相关性矩阵只覆盖内置 51 个因子。
