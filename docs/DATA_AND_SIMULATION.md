# 数据、回测与策略模拟口径

> 自用工具，不接券商、不下单。所有收益为历史/纸面模拟，不构成投资建议。

## 1. 数据源

| 数据 | 来源 | 口径 / 备注 |
|---|---|---|
| 股票列表 | 新浪 `Market_Center.getHQNodeData`，`node=hs_a` | 沪深 A 股；约 5,500+ |
| 北交所列表 | 新浪 `node=hs_bjs` | 约 250+；日线走新浪不复权兜底 |
| ETF 列表 | 新浪 `node=etf_hq_fund` | 约 900+；剔除保证金/货币/短融/日利/债类，避免平坦序列 |
| 个股/ETF 日线 | 腾讯 `proxy.finance.qq.com/.../fqkline`，`qfq` | 前复权；volume 单位为手，统一乘 100 变股 |
| 北交所日线 | 新浪 `CN_MarketData.getKLineData` | 不复权；无前复权源 |
| 当前估值 | 新浪列表 `per` / `pb` / `mktcap` / `nmc` | 当前快照，不是历史 |
| 估值历史 | 东方财富 `RPT_VALUEANALYSIS_DET` | 可选；可能限流；价值因子回测用 |
| 基准 | 腾讯 `sh000300` | 沪深300；所有策略的统一基准 |

### 估算字段

腾讯日线只给 OHLCV。为了做流动性/换手类因子：

- `amount ≈ volume(股) × close`；
- `turnover ≈ volume(股) / floatShares × 100`，`floatShares ≈ floatCap / price`（当前流通股本，历史近似）；
- 当前快照的 `amount` / `turnover` 来自新浪，是真实值；历史日线是估算。

这会影响 `AMOUNT20`、`TURNOVER20`、`AMIHUD20`、球队硬币的换手翻转等因子。方向可用，精度不如交易所口径。

## 2. 同步策略

| 模式 | 资产范围 | 用途 |
|---|---|---|
| 快速同步 | 市值前 300（约 240 股票 + 60 ETF） | 首次启动，1–3 分钟 |
| 日常更新 | 市值前 800（约 640 股票 + 160 ETF） | WorkManager 每日 16:10 |
| 全量下载 | 全部股票 + ETF + 北交所 | 手动，耗时较长 |
| 估值历史 | 回测池前 800 | 价值/低 PE 历史回测前手动跑一次 |

- 首次同步会拉 300 根日线；日常只拉缺失交易日（最多 300 根）。
- 同步后会 `pruneStocks`：用最新列表清理退市/被剔除的旧代码；用户自选/策略保留。
- 数据源限流时：腾讯 `fqkline` 换 `proxy.finance.qq.com` 主机；新浪分页之间 60ms 延迟；东财估值失败会显示错误，不阻塞行情。

## 3. 因子 vs 策略

### 因子（Factor）

只产生横截面分数，不构成买卖：

- 趋势/阻力：RSRS 右偏、RSRS 标准分、RSRS 斜率、RSRS R²、LLT、MA20/60、距 MA60、距 20 日高、60 日回撤。
- 量价/微观：量比、量价背离、换手稳定、成交额稳定、球队硬币、隔夜距离、日间/日内反转、低换手、成交额、Amihud。
- 风险：20/60 日波动、ATR、特质波动、Beta、MAX、偏度、峰度。
- 传统动量/反转：5/20/60/120/250 日、RSI14（保留，不做主打）。
- 估值：PE、PB、市值（当前截面；历史回测需估值历史）。

因子在 `因子` 页手动选择、调权重、看 TopK 候选。**因子页没有“收益”概念**。

### 策略（Strategy）

```text
Universe(股票/ETF/全部, 池大小)
+ Factors(因子 + 权重)
+ TopK(买入分数最高的 N 只)
+ Rebalance(每 N 个交易日)
+ Risk(止损/止盈/最大持有天数)
+ Execution(收盘信号 → 次日开盘, 整手 100 股/科创 200, 佣金+印花税+滑点)
```

- 内置策略：RSRS 右偏趋势、球队硬币、量价稳定、低特质波动·彩票回避、LLT 低延迟趋势、新因子复合。
- 自定义策略：在 `因子` 页选好因子后点“存为策略”，命名保存；保存后自动进入模拟。
- 策略页的“持仓 N 只”即 TopK；回测页可改。

## 4. 回测口径

- 初始资金 **100 万**；等权；整手 100 股（科创 200 股起）；剩余现金留存。
- 信号：收盘后计算因子分数；**次日开盘**成交（T+1，避免用当日收盘价成交的前视）。
- 调仓：每 `rebalanceDays` 个交易日调仓；只卖出跌出目标的，仍在目标里的继续持有。
- 风控：每日收盘检查止损/止盈/最大持有天数；次日开盘卖出。
- 涨停不买、跌停不卖（按板块/ST 设置涨跌停；ETF 按 10%；新股前几日近似无涨跌停）。
- 成本：佣金 8bps + 卖出印花税 5bps + 过户费 0.1bps + 滑点 5bps；不含冲击成本。
- 基准：沪深300 价格指数；超额 = 策略收益 - 基准收益。
- 统计：总收益、年化、最大回撤、夏普、波动、胜率、交易数、平均持有天数、累计费用、池大小。
- 估值因子：历史估值缺失自动降权；建议先同步估值历史。

**偏差**：当前股票池（幸存者偏差）；ETF 池经过剔除；成交额/换手为估算；BSE 不复权；未模拟分红税、融券、停牌排队。

## 5. 创建后模拟

策略保存时写入 `created_at`。`PaperRepository` 每日：

1. 用同一套 `BacktestEngine` 从创建日重算到最新交易日；
2. 得到纸面持仓、现金、净值；
3. 与上一次 `paper_state` 对比，生成买入/卖出/继续持有；
4. 写入 `paper_state` / `paper_equity`（全量净值点）/ 最近 200 笔交易；
5. 有买卖时：
   - 策略卡显示红色 `调仓 · 买N 卖N`；
   - 底部“策略/模拟”显示红点；
   - 发本地通知（已授权时）。

没有调仓时显示“今日无调仓 · 持仓 N 只”，持仓继续。若目标为空（例如全部被过滤），会清仓并持有现金，模拟页显示卖出。

### 模拟详情

策略卡右上角“详情 →”：

- 创建后收益、基准、现金；
- 全量纸面净值曲线（≥2 个净值点时）；
- 实际持仓（代码、股数、入选日期、权重、入选价、现价）；
- 最近 12 笔交易流水（买卖日期、盈亏、费用、原因）；
- 今日调仓提示。
- 顶部“立即核对 →”手动重算一次（不等 16:10）。

### 编辑策略

- 自定义策略可在策略页直接改因子权重、持仓数、调仓/止损；
- 保存修改会**重置创建后模拟**（从今天重新开始），旧净值清空；
- 内置策略只能“另存为我的策略”，不会修改内置定义。

### 每日时间线

```text
16:10  WorkManager 同步日线（默认市值前800）
16:1x  策略重算 → 对比持仓 → 纸面净值
16:1x  有调仓 → 红标 + 通知；无调仓 → “持仓继续”
```

非交易日：没有新日线，纸面净值不变。

## 6. 已知限制

- 不接券商，不下单；“模拟”是纸面组合。
- 数据源是公开接口，可能限流/变更；失败会显示在数据页。
- 当前池有幸存者偏差；ETF 过滤是启发式（按名称）。
- 回测未模拟冲击成本、涨跌停排队、分红税、融券费用。
- 纸面模拟仍是“创建日重跑”，不是严格冻结账本；已持久化净值/交易。
- 估值历史依赖东方财富，可能请求失败；价值因子结果仅作参考。
- 所有策略/回测均不代表未来收益，不构成投资建议。
