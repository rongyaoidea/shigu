# 期权模拟（510050 / 510300）

> 只做多期权：看涨买 call，看跌买 put；卖出只用于平仓/调仓。不卖裸期权、不接券商、不是实盘。

## 1. 范围

- 标的：510050 上证 50ETF、510300 沪深 300ETF。
- 只使用沪市 ETF 期权（合约代码 100xxxxxxxx）。
- 合约单位 10,000 份，欧式行权，实物交割。
- 目标合约：最近一个剩余 >=3 天的到期月，按标的价找平值附近，再按行权价档位偏移。
- 每次只买 1–20 张，不卖开仓。

## 2. 方向信号

用 ETF 的现有技术因子做投票：

- 趋势：RSRS 右偏、LLT、MA20/60、MA60 距离、20 日高、回撤；
- 反转/动量：5/20/60/120 日收益、RSI；
- 量价：量比（阈值 1.0）。

内置方向策略：

| id | 名称 | 规则 |
|---|---|---|
| rsrs_llt | RSRS + LLT | RSRS 0.55 + LLT 0.45 |
| llt_ma | LLT + 均线 | LLT 0.5 + MA 0.3 + MA60 0.2 |
| ma_trend | 双均线方向 | MA20/60 0.45 + 距MA60 0.3 + RET20 0.25 |
| momentum | 量价动量 | RET20 0.4 + RET60 0.3 + 量比 0.3 |
| composite | 综合方向 | RSRS 0.3 + LLT 0.25 + MA 0.25 + RET20 0.2 |

评分 = 各因子符号投票 × 权重 / 有效权重；`>= +0.25` 看涨，`<= -0.25` 看跌，其余中性。
“自选因子”可只从 ETF 方向因子中选，保存为自定义方向。

## 3. 调仓规则

- 每个交易日收盘后计算方向。
- 看涨：目标为 call；看跌：目标为 put；中性：不持仓。
- 若方向反转（call↔put）、剩余到期 <=2 天或已到期：卖出旧仓，买入目标合约。
- 同方向持续期间只持有，不因为平值/行权价漂移每天换合约。
- 卖出只用于平仓/调仓，不卖开仓。
- 纸面按当前快照价记账；不是按次日开盘成交的历史回测。
- 到期按内在价值做纸面估算；实际 ETF 期权是实物交割，纸面不等同真实交割流程。

## 4. 数据

- 合约/快照：东方财富期权列表 `fs=m:10`，每页 100 条分页，过滤 `f13=10`、代码 100 开头、名称 50ETF/300ETF。
  - `f2` 最新价、`f3` 涨跌幅、`f5` 成交量、`f6` 成交额、`f108` 持仓量、`f161` 行权价、`f162` 剩余天数。
- 日线：新浪 `StockOptionDaylineService.getSymbolInfo?symbol=CON_OP_<code>`（当前期权部分使用快照，不依赖日线）。
- 标的 ETF 日线：复用本地 ETF 日线；缺失时从腾讯补 300 条。
- 免费源可能限流/变更；合约以同步时的快照为准。

## 5. 已知限制

- 没有历史期权回测；只做当前快照 + 每日纸面。
- 没有 IV/Greeks、买卖盘口、冲击成本、保证金/强平模型。
- 到期实物交割仅按内在价值估算。
- 只覆盖 510050/510300，不覆盖 500ETF、创业板ETF、科创50ETF 等。
- 数据非实时，约 15 分钟延迟；不构成投资建议。
