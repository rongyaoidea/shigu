手绘只作用于边框、下划线与章；文字永远清晰。卡片倾角 ±0.3°，章 -6°，不做弹跳。

Motion
  • 弹簧 damping 0.86 / stiffness 900，过冲极小
  • 快移 170ms；内容换字 140ms 短模糊
  • 切页 1/8 屏宽横移 + 淡入淡出，方向跟随 tab 顺序
  • 数字变化 只做 blur + 轻微上移，不滚动、不跳动
  • 禁止 bounce / glow / 粒子 / 控件渐变 / 无限循环动画

动效预算：一屏同时最多一个“主动作”。数据加载用骨架纸纹，不用 spinner。

A先给口径，再给数字

“37 只”旁边永远有“全市场 5,326”“6 个条件”“10:12”。没有口径的数字不做主视觉。

B风险与理由同屏

个股页先写“为什么命中”，紧接着写“先看风险”。不把风险藏进二级页。

C不出现买卖动词

用“加入观察 / 写判断 / 复盘”，不用“买入 / 卖出 / 推荐 / 目标价”。

D空态也说人话

“还没有观察标的。从一次筛选开始，或手动添加一只要跟踪的股票。”不卖萌、不催付费。
